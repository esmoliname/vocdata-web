- **Fondo de Secciones:** Usar gradientes de #0B1121 a #1E293B para dar profundidad tecnológica. Alternar con #FFFFFF para secciones de contraste.
- **Acentos:** #4A90D9 (azul brillante) para botones, enlaces y elementos interactivos.
- **Éxito / Calidad:** #2ECC71 (verde) para métricas y elementos de confianza.
- **Textos:** #FFFFFF para títulos, #CBD5E1 para subtítulos, #94A3B8 para textos secundarios.
- **Fondo de Tarjetas:** #1E293B con opacidad 0.8 y efecto glassmorphism (blur de 10px).

### 1.2. Tipografía (OBLIGATORIA)
- **Fuente Única:** **Inter** (Google Fonts) en todos los textos de las secciones a mejorar.
- **Jerarquía:**
    - Títulos (H2): Inter SemiBold, 32-40px, #FFFFFF, con text-shadow de 0 2px 15px rgba(0,0,0,0.4).
    - Títulos de sección (H3): Inter SemiBold, 24-28px, #FFFFFF.
    - Cuerpo de texto: Inter Regular, 16-18px, #CBD5E1.
    - Textos pequeños: Inter Regular, 14px, #94A3B8.

### 1.3. Fondos Dinámicos
- **Capa 1:** Gradiente #0B1121 a #1E293B.
- **Capa 2:** Patrón de líneas de datos o código (opacidad 0.05, color #4A90D9).
- **Capa 3:** Imagen abstracta de red de datos o conexiones (opacidad 0.1, blur de 6px).

### 1.4. Animaciones y Efectos Generales
- **Animación de entrada (Scroll):** Fade-in y slide-up al hacer scroll.
- **Micro-interacciones:** Hover con cambio de color y sombra (transición de 0.3s) en botones y tarjetas.
- **Efecto Parallax:** Movimiento sutil del fondo en secciones clave.
